# 豆包动态启动

macOS 上的豆包启动动画。点击独立启动器后，它打开已安装的豆包，在豆包窗口内播放约 9 秒的开场动画，结束后显示原应用。豆包安装包和用户数据不会被改写。

## 使用

1. 安装官方豆包和 Node.js 20+。
2. 双击 `dist/豆包动态启动.app`。首次从终端构建后，也可将这个应用拖到 Dock。
3. 豆包已运行时，启动器会提示先保存未发送的内容，再退出并重开。
4. 在豆包窗口按 `⌘⌥B` 打开素材设置；可替换头像、主画面、动态视频和三处文字。点击「保存并预览」后，素材保存在本机的 IndexedDB。按 `Esc` 可跳过动画。

图片支持 PNG/JPEG/WebP，大小不超过 30 MB；视频支持 MP4/WebM，大小不超过 50 MB、最高 1080p、时长至少 1 秒。动态视频和主画面请使用同一场景，这样切换才自然。

## 构建

需要 macOS 12+、Xcode 命令行工具和 Node.js 20+。

```sh
node --test tools/extension.test.mjs
./tools/build.sh
```

产物在 `dist/豆包动态启动.app`。可选的本地默认素材是 `assets/avatar.jpg`、`assets/artwork.jpg` 和 `assets/startup.mp4`；没有这些文件时使用仓库内的示例 SVG，视频部分留空。个人媒体文件和构建产物被 `.gitignore` 排除，公开仓库只包含可替换的源码与示例素材。

## 原理与限制

启动器检查豆包的签名和安装路径，使用仅监听本机 `127.0.0.1` 的调试端口，在豆包主页面临时放入一个动画 iframe。动画结束即移除覆盖层；快捷键可再次打开素材设置。豆包更新后，内部页面地址若发生变化，可能需要更新 `extension/cdp.mjs`。动画不能由豆包原图标触发，请从独立启动器进入。
